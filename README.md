# DeadlineIQ: Assignment Workload Predictor

## Project Goal
DeadlineIQ is a Java-based command-line application designed to help college students organize assignments and manage their study time. The program analyzes assignment deadlines, difficulty levels, and estimated completion times to help students prioritize tasks and avoid last-minute workload buildup.

## MVP Features
- Add and view assignments with deadlines, difficulty levels, and estimated completion times.
- Save and load assignment data using CSV files.
- Calculate assignment priority scores based on deadlines, difficulty, and workload.
- Identify days with heavy workloads.
- Recommend study schedules based on assignment deadlines and available daily study hours.

## Future Plans
- Edit and delete existing assignments.
- Track assignment completion and progress.
- Display visual charts of weekly workloads.
- Improve time estimates using previous assignment data.

## Tech Stack
- **Language:** Java
- **Development Environment:** Eclipse or Visual Studio Code
- **Libraries:** java.util, java.time, java.io
- **Data Storage:** CSV files
- **Interface:** Command-line interface
- **Version Control:** Git and GitHub
- **External APIs:** None
